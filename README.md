# 그림 놀이

4~6세 아이가 **색칠하기**와 **따라 그리기**를 하며 노는 앱입니다. 휴대폰 앱(Android)으로도, 일반 브라우저에서도 돌아갑니다. 인터넷이 없어도 됩니다.

처음 켜면 아이 이름을 묻고, 첫 화면 제목이 "○○의 그림 놀이"가 됩니다.

## 무엇을 하나

### 🎨 색칠하기
- 그림 24장 (쉬운 것부터): 사과 · 풍선 · 하트 · 별 · 물고기 · 집 · 해 · 아이스크림 · 우산 · 버섯 → 꽃 · 자동차 · 고양이 · 배 · 나무 · 눈사람 · 거북이 → 나비 · 공룡 · 로켓 · 기차 · 성 · 토끼 · 부엉이
- **👆 눌러서 채우기** (기본): 색을 고르고 칸을 톡 누르면 그 칸이 채워집니다.
- **🖌️ 손가락 붓**: 손가락을 댄 칸 안에서만 칠해집니다. 선 밖으로 나가지 않습니다.
- ↩️ 되돌리기. 칠하던 그림은 자동 저장돼서, 나갔다 와도 이어서 칠합니다.
- ✅ 를 누르면 완성! 칭찬과 함께 **내 그림첩**에 저장됩니다. 모든 칸을 다 칠하면 ✅ 가 반짝입니다.

### ✏️ 따라 그리기
- 선 6개(가로 · 세로 · 번개 · 물결 · 계단 · 꼬불꼬불), 도형 7개(동그라미 · 세모 · 네모 · 하트 · 별 · 마름모 · 초승달), 한 획 그림 6개(물고기 · 사과 · 집 · 풍선 · 아이스크림 · 버섯)
- ✨ **여러 획 그림** 6개 (윗단계): 웃는 얼굴 · 해 · 꽃 · 집 · 눈사람 · 나무. 큰 모양부터 그리고 눈·햇살·문 같은 세부를 차례로 그립니다. 지금 그릴 획의 점선만 진하게 보입니다.
- 반짝이는 점에서 시작해 점선을 따라갑니다. 중간에 손을 떼면 그 획만 다시.
- 다 그리면 ▶️ 다음, 그리고 같은 모양의 색칠 그림이 있으면 🎨 로 바로 칠하러 갑니다.

### 📒 내 그림첩
- 완성한 그림이 최신 순으로 모입니다. 누르면 크게 보고, 🎨 로 같은 그림을 새로 칠할 수 있습니다.
- 아이 화면에서는 지울 수 없습니다.

### 부모 메뉴
- 첫 화면의 🔒를 3초 동안 누르고 있으면 열립니다.
- 볼륨, 아이 이름 바꾸기, 그림첩 그림 지우기(두 번 눌러 확인), 모든 그림 기록 지우기.

## 실행하기

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev        # 브라우저에서 보기 (http://localhost:5173)
npm run dev:test   # 테스트 모드: 부모 메뉴 한 번 눌러 열기
npm test           # 테스트 실행
npm run build      # 배포용 웹 빌드 (dist/, 오프라인 PWA)
```

## Android 앱(APK) 만들기

`android/` 폴더는 저장소에 올리지 않습니다. 처음 한 번은 직접 만들어야 합니다.

준비물:
- Android Studio (Android SDK)
- JDK 21. Gradle 8.14가 Java 25에서는 돌지 않습니다.

```bash
npx cap add android   # 처음 한 번만
npm run apk           # 웹 빌드 → 동기화 → 디버그 APK 빌드
```

- 결과물: `android/app/build/outputs/apk/debug/app-debug.apk`. 휴대폰으로 옮겨 설치하면 됩니다. 다시 설치하면 업데이트로 깔리고 그림은 유지됩니다.
- 놀이 학교와 다른 앱(`com.family.kidsDrawing`)이라 나란히 설치됩니다.
- JDK 위치는 `ANDROID_STUDIO_JBR` 또는 `JDK21_HOME` 환경 변수로 지정할 수 있습니다 (`scripts/build-apk.mjs` 참고).
- 휴대폰 **뒤로 가기** 버튼은 이전 화면으로 갑니다. 첫 화면에서는 아무 반응이 없어서 아이가 실수로 앱을 끄지 않습니다.
- 홈 버튼까지 막고 싶으면 Android **앱 고정** 기능을 쓰세요: 설정 → 보안(또는 보안 및 개인정보 보호) → 기타 보안 설정 → 앱 고정 켜기 → 최근 앱 화면에서 그림 놀이 아이콘을 눌러 "고정".

## 기술

- Vite + TypeScript. 프레임워크 없이 DOM을 직접 다룹니다.
- 색칠 그림은 0~100 좌표의 SVG path 칸들입니다. 칸은 뒤에서 앞 순서로 겹쳐 그리고, 칠한 내용은 "동작 목록"(채우기 / 붓 한 획)으로 저장해 캔버스에 다시 그립니다.
- 저장: 칠하던 상태와 그림첩은 IndexedDB, 이름과 볼륨은 localStorage. 서버로 보내는 데이터는 없습니다.
- 테스트: Vitest (jsdom, fake-indexeddb). 오프라인: vite-plugin-pwa. 앱 포장: Capacitor (Android).

```
tests/               로직·화면 테스트
docs/superpowers/    설계 문서와 구현 계획
scripts/             APK 빌드, 아이콘 생성
```
