# 따라 그리기: 그림만, 더 너그러운 터치, 다음 버튼 — 설계 (작은 변경)

## 왜
부모: 직선·도형은 아이가 흥미 없어 함. 그림 따라 그리기를 늘리고, 아이 손이라 터치가 더 잘 먹었으면, 다음(▶️) 버튼이 미디어 플레이어 같음.

## 목표
- 선(6)·도형(7) 묶음 삭제. 두 줄만: 🖼️ 한 획 그림 11개, ✨ 여러 획 그림 12개 (모두 23개).
  - 한 획: 물고기 사과 풍선 하트 별 집 아이스크림 버섯 우산 거북이 고양이.
  - 여러 획: 얼굴 해 꽃 집 눈사람 나무 + 배 자동차 나비 로켓 토끼 부엉이.
  - 얼굴 말고는 모두 같은 색칠 그림과 연결(🎨).
- 터치: 허용 거리 0.12 → 0.17. 손을 떼도 그린 데까지 유지. 손가락이 체크포인트 하나를 건너뛰어 앞서 있으면 따라잡고, 손가락 근처 체크포인트는 한 번에 여러 개 지나감.
- 다음 버튼: ▶️ 대신 다음 그림의 이모지가 통통 튀는 동그라미 버튼.

## 하지 않는 것
획 순서 자유, 방향 무시, 잠금·점수.

## 접근
- 고른 것: 판정은 그대로 "순서대로 체크포인트"에 너그러움만 더함 — 예측 가능하고 테스트 쉬움.
- 버린 것: 모양 유사도 판정 — 엔진을 새로 써야 하고 4~6세에게 결과가 헷갈림.
