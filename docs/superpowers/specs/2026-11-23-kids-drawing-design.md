# 유아 그림 놀이 (색칠하기 · 따라 그리기) 설계

작성일: 2026-11-23

## 1. 목적과 배경

- 4~6세 아이가 **색칠하기**와 **따라 그리기**를 하며 노는 앱이다.
- 사용자는 요청자 본인의 아이 한 명. 배포는 **요청자 휴대폰(Android) 한 대에 APK를 직접 설치**한다. 스토어 배포는 하지 않는다.
- 웹앱으로 만들고, 브라우저에서도 그대로 돌아가야 한다 (개발·확인용).
- 분위기와 기술은 같은 요청자의 기존 프로젝트 `D:\myproject\kids-learning`(놀이 학교)과 맞춘다.
- 색칠하기가 더 쉬운 놀이이므로 앱의 중심이고, 따라 그리기는 한 단계 위 놀이다.

## 2. 목표 / 비목표 / 실패 조건

**목표**
- 글을 못 읽는 아이가 부모 도움 없이 혼자 그림을 골라 칠하고, 따라 그리고, 완성할 수 있다.
- 4살도 바로 할 수 있는 쉬운 색칠(눌러서 채우기)과, 커서도 재미있는 손으로 칠하기(붓)를 둘 다 준다.
- 완성한 그림이 **내 그림첩**에 남아서 아이와 부모가 다시 볼 수 있다.

**비목표 (첫 버전)**
- 별·점수·단계 잠금. 모든 그림은 처음부터 열려 있다.
- 백지 자유 그리기, 사진 불러와 색칠하기
- 그림첩을 휴대폰 사진첩으로 내보내기·공유
- 계정, 동기화, 서버, 광고, 결제, iOS 빌드

**실패 조건 (동작은 해도 실패로 보는 경우)**
- 아이가 글을 읽어야만 진행할 수 있다.
- 칠하다가 망쳐서 되돌릴 수 없다, 혹은 틀렸다고 혼나는 느낌을 준다 (X 표시, 경고음).
- 손가락으로 칠한 색이 선 밖으로 번져 그림이 지저분해진다.
- 터치가 굼뜨거나 손가락을 따라오지 않아 답답하다.
- 아이가 실수로 부모 메뉴나 앱 밖으로 나간다, 혹은 그림첩을 지운다.

## 3. 제약

- 한 코드로 브라우저와 Android 앱을 함께 지원한다. 첫 실행 이후 오프라인 동작.
- 터치 영역 최소 약 64px. 휴대폰 세로·가로, 태블릿 모두.
- 데이터는 기기 안에만 저장한다. 외부로 아무것도 보내지 않는다.

## 4. 검토한 방법 (Approaches)

### 4.1 앱 형태 — kids-learning과 같은 방식 (요청자가 위임, 내 판단)
Vite + TypeScript(프레임워크 없이 DOM 직접), vite-plugin-pwa로 오프라인, Capacitor로 Android 포장, Vitest(jsdom) 테스트. 다른 방식(Flutter, React Native)은 요청자가 이미 이 방식으로 앱을 만들어 쓰고 있고 빌드 흐름(`npm run apk`)까지 갖춰져 있어서 고려할 이유가 없다.

### 4.2 색칠 그림을 어떻게 표현할까

| 방법 | 장점 | 단점 |
|---|---|---|
| **① SVG 칸(영역) 방식** ✅ 선택 | 칸마다 닫힌 path라 "누르면 그 칸 채우기"가 정확하고 즉시. 붓은 그 칸 모양으로 잘라서(clip) 칠하면 선 밖으로 안 나감. 어떤 화면 크기에서도 선이 선명. 그림을 직접 그려 넣기 쉬움 | 그림을 칸 단위로 설계해야 함 |
| ② 선화 PNG + 캔버스 flood fill | 아무 선화나 쓸 수 있음 | 채우기가 픽셀 단위라 느리고 선 틈으로 새기 쉬움, 확대 시 흐림, 붓을 선 안에 가두기 어려움 |
| ③ 캔버스에 직접 그린 벡터 + 자체 hit test | 렌더링 통제가 쉬움 | ①과 같은 일을 손으로 다시 구현 |

**선택: ①** (요청자가 "추천대로" 위임). 그림은 우리가 직접 그리므로 ②의 장점이 필요 없다.

### 4.3 색칠 방식 — 요청자 결정
**둘 다.** 기본은 **눌러서 채우기**, 🖌️ 버튼으로 **손가락 붓**으로 바꾼다.

### 4.4 완성 후 — 요청자 결정 (내 추천을 수락)
축하 + 칭찬 음성 + **내 그림첩 저장**. 별·잠금 없음.

## 5. 결정된 내용

### 5.1 화면 구성

```

│ ○○의 그림 놀이  🔒 │       │ ←  🎨 색칠하기     │       │ ←      🐟           ↩️  ✅  │
│                   │       │ [🐟][🍎][🏠][🌸]  │       │                             │
│  ┌─────┐ ┌─────┐  │       │ [🚗][🐱][☀️][🎈]  │       │       [ 큰 그림 영역 ]       │
│  │ 🎨  │ │ ✏️  │  │       │ [🦋][🐘][🚀][🦖]  │       │                             │
│  │색칠 │ │따라 │  │       │  (썸네일 = 칠한    │       │ 🔴🟠🟡🟢🔵🟣🩷🤎⚫⚪   👆/🖌️ │
│  └─────┘ └─────┘  │       │   진행 상태 반영)  │       └─────────────────────────────┘
│      📒 그림첩     │       └───────────────────┘
└───────────────────┘
```

- **첫 화면**: 🎨 색칠하기(크게, 왼쪽/위), ✏️ 따라 그리기, 📒 내 그림첩. 구석에 🔒 부모 메뉴.
- 처음 켜면 kids-learning처럼 아이 이름을 묻고, 제목이 "○○의 그림 놀이"가 된다.
- 화면에 글자가 있어도 아이는 그림·이모지로 알아볼 수 있어야 하고, 주요 안내는 음성으로 한다 ("어떤 그림을 칠할까?", "다 했어? 멋지다!").

### 5.2 색칠하기

- **그림 고르기**: 그림 썸네일 격자. 칠하던 그림은 썸네일에 칠한 상태가 보인다.
- **팔레트**: 큰 동그라미 10색 (빨강, 주황, 노랑, 초록, 파랑, 보라, 분홍, 갈색, 검정, 흰색). 선택한 색은 커지고 테두리가 생긴다. 세로 화면은 아래, 가로 화면은 옆.
- **👆 눌러서 채우기 (기본)**: 칸을 톡 누르면 그 칸 전체가 선택한 색으로 바뀐다. 짧은 "뽁" 효과(살짝 커졌다 돌아오기). 이미 칠한 칸도 다시 누르면 새 색으로 바뀐다.
- **🖌️ 손가락 붓**: 손가락을 댄 칸 안에서만 칠해진다. 그 칸 밖으로 손가락이 나가도 색은 칸 경계에서 잘린다 (손가락을 뗄 때까지 처음 댄 칸에 고정). 붓 굵기는 하나(그림 크기의 약 4%)로 고정.
- 붓으로 칠한 칸을 채우기로 누르면 그 칸의 붓 자국은 지워지고 단색으로 채워진다.
- **↩️ 되돌리기**: 마지막 동작(채우기 한 번, 또는 붓 한 획) 하나씩 취소. 최소 20단계.
- **전부 지우기**는 아이 화면에 두지 않는다 (실수 방지). 대신 되돌리기로 충분하다. 처음부터 다시 하고 싶으면 그림첩 저장 후 같은 그림을 다시 열면 새 그림으로 시작한다 (5.4 참고).
- **✅ 다 했어요**: 언제든 누를 수 있다. 모든 칸을 다 칠하지 않아도 완성 처리한다 (아이가 정한 게 완성이다). 모든 칸이 칠해지면 ✅ 버튼이 반짝여서 눌러보게 유도한다.
- 선(검은 윤곽)은 항상 색 위에 그려져서, 붓으로 칠해도 선이 덮이지 않는다.
- **진행 자동 저장**: 그림마다 칠하던 상태를 기기에 저장. 나갔다 와도 이어서 칠한다. 앱을 껐다 켜도 유지.

### 5.3 따라 그리기

- kids-learning의 따라 쓰기 원리를 그대로 쓴다: 점선 위에 체크포인트가 있고, 손가락이 다음 체크포인트 근처(허용 거리)를 지나면 한 칸 전진한다. 획 중간에 손을 떼면 그 획만 처음부터. 시작점은 반짝이는 점으로 표시하고, 지나간 부분은 진한 색으로 채워진다.
- **세 묶음**(잠금 없음, 고르는 화면에서 묶음별로 줄을 나눠 보여준다):
  1. **선**: 가로선, 세로선, 지그재그, 물결 (4개)
  2. **도형**: 동그라미, 세모, 네모, 하트, 별 (5개)
  3. **그림**: 물고기, 사과, 집, 풍선 등 (4개 이상)
- 다 그리면 축하하고, **다음 그림**(▶️) 버튼을 보여준다. 같은 모양의 색칠 그림이 있는 항목에는 **바로 색칠하러 가기**(🎨) 버튼도 함께 보여준다.
- 색칠 연결이 있는 항목 (내 판단): 하트, 별, 물고기, 사과, 집, 풍선. 선 묶음과 동그라미·세모·네모는 연결 없이 다음으로만 간다. 데이터에서는 따라 그리기 항목이 색칠 그림 id를 선택적으로 가리킨다.
- 따라 그린 결과는 그림첩에 저장하지 않는다 (그림첩은 색칠 작품만).

### 5.4 내 그림첩

- ✅로 완성한 색칠 그림을 이미지로 저장한다 (선 + 채우기 + 붓 자국을 한 장으로 합성).
- 그림첩 화면: 완성한 그림 격자, 최신이 앞. 누르면 크게 보기.
- 같은 그림을 여러 번 완성하면 각각 따로 저장된다. 완성하면 그 그림의 진행 상태는 비워져서, 다음에 열면 새로 칠한다.
- 아이 화면에서는 지울 수 없다. 지우기는 부모 메뉴에서만.
- 저장 공간이 많이 필요하므로 이미지는 localStorage가 아니라 **IndexedDB**에 둔다. 진행 상태도 IndexedDB.

### 5.5 그림 내용 (첫 버전)

- 색칠 그림 **12장** (내 판단), 쉬운 것부터:
  - 칸 4~6개: 사과, 풍선, 하트, 별, 물고기, 집
  - 칸 7~10개: 꽃, 자동차, 고양이
  - 칸 10~15개: 나비, 공룡, 로켓
- 하트와 별처럼 원래 한 칸인 모양은 안쪽을 나눠서(줄무늬, 얼굴 등) 칸 4개 이상으로 만든다. 바깥 윤곽만 따라 그리기 모양과 같으면 된다.
- 따라 그리기 **13개 이상** (5.3).
- 그림은 직접 SVG로 그린다. 두꺼운 둥근 검은 선, 칸은 아이 손가락으로 누르기 충분히 크게 (가장 작은 칸도 화면에서 손가락 하나 크기 이상).
- 색칠 연결이 있는 따라 그리기 모양은 대응하는 색칠 그림의 바깥 윤곽과 같아야 한다 (따라 그린 뒤 색칠로 넘어갈 때 어색하지 않게).

### 5.5.1 Android 뒤로 가기 버튼 (내 판단)

- `@capacitor/app`으로 뒤로 가기 버튼을 가로챈다. 앱 안에서는 이전 화면으로 가고, **첫 화면에서는 아무 일도 하지 않는다** (실수로 앱이 꺼지지 않게).
- 홈 버튼까지 막는 잠금은 하지 않는다. 필요하면 부모가 Android 화면 고정 기능을 쓴다 (README에 안내).

### 5.6 부모 메뉴

- 🔒를 3초 누르고 있으면 열림 (kids-learning과 같음).
- 볼륨, 아이 이름 바꾸기, 그림첩 그림 지우기(한 장씩, 확인 한 번 더), 모든 기록 초기화.

### 5.7 분위기

- kids-learning의 디자인 토큰을 그대로 가져온다: 크림→하늘 그라데이션 배경, `Jua` 폰트, 파스텔 카드, 둥근 모서리, 부드러운 그림자, 큰 버튼.
- 축하: kids-learning의 별 터지는 오버레이 + 칭찬 음성 ("우와, 멋진 물고기다!").
- 음성: kids-learning과 같은 방식 (브라우저는 Web Speech, 앱은 기기 TTS 플러그인).

### 5.8 kids-learning에서 가져올 것

공용 패키지로 묶지 않고 **복사해서 이 프로젝트에 맞게 고친다** (두 앱이 따로 바뀌어도 서로 영향 없게).
- `src/core/audio.ts`, `nativeTts.ts`, `offline.ts`, `profile.ts`, `trace.ts`, `devFlags.ts`
- `src/ui/dom.ts`, `celebrate.ts`, `longPress.ts`, `setup.ts`(이름 묻기), 부모 메뉴 골격
- `src/styles.css`의 토큰과 공통 스타일
- `scripts/build-apk.mjs`, `gen-icons.mjs`, `check-precache.mjs`, `vite.config.ts`, `capacitor.config.ts` 구성
- 해시 라우터 패턴 (`router.ts`)

### 5.9 앱 정보

- 앱 이름: **그림 놀이**, appId: `com.family.kidsDrawing` (kids-learning과 다른 앱으로 나란히 설치되게).
- localStorage 키 접두어: `kidsdraw.` (kids-learning의 `kidsgame.`과 겹치지 않게). IndexedDB 이름: `kidsdraw`.

## 6. 빌더에게 맡기는 것

- 그림 SVG 데이터의 정확한 형식 (칸 path에 id를 붙이는 방식 등), 칸 판정 방법 (`elementFromPoint` / `isPointInFill` 등).
- 붓 구현 세부: 캔버스 레이어 구성, 칸 clip 방법, 되돌리기 저장 방식 (스냅샷 vs 획 기록). 단, 붓이 손가락을 지연 없이 따라와야 한다 (실패 조건).
- 저장 이미지 해상도 (그림첩 크게 보기에서 선명한 정도면 충분, 장당 수백 KB 이하 권장).
- 개별 그림 목록과 색칠 그림의 정확한 소재 (5.5의 범위 안에서).
- 화면 전환 애니메이션, 효과음 유무.
- 테스트 범위 (로직 위주: 채우기/붓 상태, 되돌리기, 따라 그리기 진행, 저장/불러오기).
