# 그림 더 늘리기 + 여러 획 따라 그리기 — 설계

## 왜
처음 버전(색칠 12장, 따라 그리기 13개)을 써 본 부모가 "개수가 더 많으면 좋겠고, 따라 그리기는 윗단계도 있으면 좋겠다"고 했다.
윗단계는 부모가 고른 방식: **여러 획으로 그림 하나를 완성하기** (점선 없이 그리기, 글자·숫자는 고르지 않음 — 글자는 kids-learning에 이미 있다).

## 목표
- 색칠 그림 12 → 24장. 단계마다 4장씩: 쉬움 해·아이스크림·우산·버섯 / 중간 배·나무·눈사람·거북이 / 어려움 기차·성·토끼·부엉이.
- 따라 그리기 13 → 25개.
  - 선 +2 계단, 꼬불꼬불 / 도형 +2 마름모, 초승달 / 한 획 그림 +2 아이스크림, 버섯 (색칠 그림과 연결).
  - 새 묶음 `multi` (✨ 줄): 웃는 얼굴 → 해 → 꽃 → 집 → 눈사람 → 나무. 큰 모양 먼저, 세부는 나중. 얼굴 말고는 같은 색칠 그림과 연결.
- 여러 획일 때: 지금 그릴 획 점선만 진하게, 남은 획은 흐리게, 다 그린 획은 분홍. 시작점은 지금처럼.

## 하지 않는 것
잠금·별점·점수 없음. 저장 방식, 색칠 화면, 판정 로직(advanceTrace) 그대로.

## 접근
기존 엔진이 이미 획 여러 개를 순서대로 받는다(닫힌 도형은 두 획). 그래서 **내용 추가 + 그리기 색 구분**만 한다.
다른 길(획 순서 자유, 새 판정)은 4~6세에게 더 헷갈리고 엔진을 새로 써야 해서 버렸다.

## 빌더 몫 (내 판단)
- 그림 모양·칸 나누기, 획 순서와 시작점. 칸 개수는 기존 단계 범위(쉬움 4~6, 중간 7~10, 어려움 10~15)를 지킨다.
- 여러 획 그림의 작은 세부(눈 등)는 점 하나가 아니라 짧은 획으로 — 판정이 점 두 개 이상을 요구한다.
- 다음(▶️) 순서는 목록 순서 그대로 25개를 돈다.
